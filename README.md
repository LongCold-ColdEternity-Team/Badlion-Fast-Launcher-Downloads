- 恢复 OptiFine M5 的完整视频设置，以及光影、质量、细节、性能、动画和其他设置页；保留聊天兼容修正。

完整客户端 ZIP：970,273,640 字节，约 925.3 MiB。全新安装可在配套 PCL 的“下载 → Fast Launcher”中进行，也可使用包内 start.cmd。

验证：OptiFine 六个子菜单均已渲染，Smooth FPS 开关与保存成功；本地模拟服务器禁用标记时 Perspective 能开启镜头、关闭后恢复视角；单人世界和聊天测试通过。未连接 Hypixel 实测，未代替用户完成微软账户授权。
